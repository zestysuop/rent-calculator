# 🏠 Rent Calculator in Excel

## 📌 Overview

This project is a simple Rent Calculator built using Microsoft Excel. It helps calculate each person's share of rent and other monthly expenses, making it useful for roommates, students, or anyone sharing accommodation.

The project was created to practice Excel formulas and build a beginner-friendly data analysis portfolio.

---

## ✨ Features

* Calculate total monthly expenses
* Split rent equally among roommates
* Include additional expenses such as electricity, water, internet, and maintenance
* Automatic total expense calculation
* Clean and easy-to-use layout
* Beginner-friendly Excel workbook

---

## 🛠️ Tools & Skills Used

* Microsoft Excel
* SUM Formula
* Basic Arithmetic Formulas
* Cell Formatting
* Data Organization
* Spreadsheet Design
